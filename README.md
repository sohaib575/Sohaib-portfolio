# Sohaib — Portfolio
A responsive personal portfolio website of a Computer Science student, built with plain HTML, CSS and JavaScript. It showcases education, projects, certifications, a photo gallery and a contact form, with a dark/light theme.
**Live Demo:** https://sohaibportfoliowebsite.netlify.app/


## Features
- Dark / light theme switcher (your choice is remembered in the browser)
- Animated typing effect in the hero section
- Smooth scroll-reveal animations, animated stat counters and progress bars
- Academic section with an education table
- Project cards with screenshot, tech tags, GitHub and live demo links
- Certifications section
- Gallery with a full-screen lightbox viewer
- CV section: download the CV or view it in a popup
- Contact form with input validation
- Scroll-to-top button
- Responsive layout for desktop, tablet and mobile
